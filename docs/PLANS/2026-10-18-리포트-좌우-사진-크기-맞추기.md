# 계획: 리포트 — 좌·우 사진의 몸 크기 맞추기 (리포트에서만)
상태: 진행 중        (초안 → 승인됨 → 진행 중 → 완료 / 폐기)
요청: "팔꿈치 굴곡 좌측과 우측 비교를 해봐. 같은 동작인데 사진 크기가 달라. 원본 측정사진은 절대 건들지 말고 리포트에서만 몸의 우측 기준으로 좌측 사진 크기와 비율을 맞춰줄수 있을까? 물론 온 몸 전부다 적용하고. 예를들어 발목 배측굴곡이면 우측 키기와 비율로 좌측 사진을 조절하는거야. 리포트에서만. 측정 카테고리나 회원 카테고리에서 나타나는 파일은 절대 수정되면 안되. 즉 원본은 그대로, 리포트에 나오는 화면만 바뀌는 거지."
작성일: 2026-10-18   승인일: 2026-10-18

## 한 줄 목적
리포트 '관절 가동범위'에서 같은 동작의 좌·우 사진을 나란히 볼 때, **두 사진 속 몸이 같은 크기로 보이게** 리포트용 그림만 확대해서 보여 준다. 원본 사진·측정 기록·측정 화면·회원 화면의 사진은 그대로.

## 왜 크기가 다른가
좌·우를 찍을 때 카메라와 회원 사이 거리가 매번 조금씩 달라서, 같은 몸이라도 사진 속 크기가 다르다(아요 캡처: 팔꿈치 굴곡 좌가 우보다 작게 보임). 리포트는 사진을 그대로 같은 칸 크기에 넣으므로 그 차이가 그대로 보인다.

## 어떻게 맞추나
1. **몸 크기 재기** — 측정할 때 찍은 측정점 사이 거리로 잰다. 예: 팔꿈치 굴곡 = 어깨–팔꿈치 + 팔꿈치–손목 길이, 발목 배측굴곡 = 복사뼈–비골두 + 발뒤꿈치–새끼발가락 뿌리 길이. 화면 기준선(세로선·가로선)처럼 몸이 아닌 점은 빼고 잰다. 몸 길이는 좌·우가 같으므로, 사진 속 길이가 다르면 그만큼 찍은 거리가 달랐던 것이다.
2. **우측 기준으로 좌측만 조절** (아요 답 1) — 좌측이 작게 찍혔으면 좌측을 **확대**(측정점들의 가운데를 중심으로, 사진 밖으로 나가지 않게), 좌측이 크게 찍혔으면 좌측을 **축소**(사진을 가운데에 두고, 생기는 둘레는 같은 **격자 배경**으로 이어 채움 · 격자를 끈 상태면 지금처럼 남색 배경). 우측 사진은 그대로. 사진 위 선·각도 표시의 굵기·글자 크기는 우측과 같게 유지. 그림 위쪽 제목 줄(동작·각도)은 그대로.
3. **원본은 손대지 않음** — 리포트가 사진을 그릴 때 만드는 임시 그림에만 적용한다. 저장(`roms`·`blobs`·서버)·측정 화면·회원 화면·측정 기록 엑셀은 그대로.

## 위험과 되돌리는 법
| 위험 | 일어날 때 | 되돌리는 법 |
|---|---|---|
| 확대하면서 손끝·발끝이 사진 밖으로 잘림 | 몸이 사진 가장자리에 있고 차이가 큰 경우 | 확대 상한(1.6배)과 측정점 가운데 기준 확대. 잘림이 보이면 상한을 낮춤 |
| 축소한 좌측 사진 둘레에 원본에 없던 격자만 있는 여백이 보임 | 좌측이 크게 찍힌 경우 | 격자 배경을 사진 밖까지 이어 그려 자연스럽게. 이 '이어 그리기'는 리포트 그림에만 켜서 측정 화면 격자는 그대로 |
| 측정점을 잘못 찍은 기록이면 몸 크기를 잘못 재서 엉뚱하게 확대 | 점이 크게 틀린 기록 | 상한 1.6배로 피해를 제한. 원본·측정 화면은 그대로라 점을 고치면 리포트도 바로 맞아짐 |
| 확대한 사진이 약간 흐려짐 | 많이 확대할 때 | 화면은 원본에서 다시 그리므로 1.3배 안팎은 거의 티 안 남. 공유 이미지는 900px 로 그려 여유 있음 |
| 원본 없이 작은 미리보기만 있는 예전 기록 | 사진 원본이 없는 기록 | 그 짝은 맞추지 않고 지금처럼 보임 |
| 전체 되돌리기 | — | 단계별 커밋이라 `git revert`. 원본 데이터는 바뀌지 않으므로 되돌려도 손실 없음 |

## 단계
1. **계산 + 테스트 먼저** — `report-pair.js` 와 테스트 — 확인: `npm test` (몸 크기·확대 비율·영역 계산, 상한·작은 차이 무시·점 없는 기록)
2. **화면** — 좌·우 짝을 함께 그려 확대 — 확인: 가짜 회원(홍길동)에 크기가 다른 좌·우 사진을 넣고 390px 캡처, 두 사진 속 팔 길이가 같은지 눈으로 + 수치로
3. **공유 이미지·PDF** — 같은 확대 — 확인: [리포트 이미지 저장]
4. **원본이 그대로인지 확인** — 측정 화면·회원 화면에서 같은 기록을 열어 사진·점이 예전과 같은지, 저장된 기록이 바뀌지 않았는지
5. **검토·문서** → `/ship`

## 확인이 필요한 질문 (추천 답 포함)
1. **좌측 몸이 우측보다 크게 찍힌 경우**는 어떻게 할까요? 좌측을 줄이면 사진 둘레에 빈 여백이 생깁니다. — 추천: **그때는 우측을 확대**(작게 찍힌 쪽을 키워 큰 쪽에 맞춤). 빈 여백 없이 두 사진이 같은 크기가 됩니다. "무조건 우측 기준(좌측을 줄여 여백이 생겨도)"을 원하시면 그렇게 답해 주세요.
2. **공유 이미지·PDF**에도 똑같이 적용할까요? — 추천: **네**. 회원이 받는 리포트도 같은 크기로 보입니다(이것도 원본은 그대로).
3. **최대 확대·축소는 1.6배**까지, 차이가 5% 미만이면 맞추지 않기 — 이렇게 정해도 될까요? — 추천: **네**. 측정점이 잘못 찍힌 기록에서 사진이 지나치게 커지는 것을 막습니다.
