# 테스트 전략: 아요바디요

> 자동으로 잡을 수 있는 건 자동으로, 나머지는 **실제 폰에서 점검표**로 잡는다. (ADR-000-7)

## 1. 자동 테스트 (`npm test` = `node --test tests/`)
대상: `js/logic/` 의 계산·변환 함수. 예: 각도 계산, 점수 등급, 날짜 포맷, 데이터 내보내기 형식.
규칙:
- 새 로직 함수는 **테스트를 먼저** 쓴다(TDD). 정상값 1개 · 경계값 1개 · 잘못된 입력 1개 는 기본.
- 테스트 이름은 한국어 문장: `test("두 점의 기울기 각도를 소수 1자리로 반환한다", ...)`.
- 화면(DOM)·카메라·네트워크는 자동 테스트에 넣지 않는다.

## 2. 문법·형식 검사 (훅이 자동 실행)
- `.js` 저장 시 `node --check`, `.json` 저장 시 파싱 검사. 실패하면 Claude 가 바로 고친다.

## 4. 버그를 발견했을 때
1. `/fix` 에 "어느 화면에서, 무엇을 했더니, 무엇이 잘못됐다" 를 적는다.
2. Claude 가 **먼저 실패하는 테스트**(재현)를 만들고, 고친 뒤 통과를 보여 준다.
3. 로직 밖 버그(화면)는 점검표 3번에 항목을 추가한다 → 같은 버그가 두 번 나오지 않게.
