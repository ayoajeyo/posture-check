# 계획: 목 굴곡·신전·측방굴곡을 보조선 방식으로 바꾸기
상태: 완료        (초안 → 승인됨 → 진행 중 → 완료 / 폐기)
요청: "목 굴곡 각도측정법을 바꿀꺼야. 이전에 바꾼 발목 배측굴곡, 저측굴곡처럼 보조선을 이용한 측정법으로 할거야. 1선 시작점(목관절) = 목 가장 아래쪽의 정중앙 / 1선 끝점(세로 기준선) = 목관절에서 화면의 위쪽 / 2선 시작점(턱 앞) = 턱의 전면 / 2선 끝점(이마 앞) = 이마의 전면 / 각도축 = 1선과 생성된 보조선. 1선과 2선을 모두 그리면 2선과 평행한 보조선을 자동 생성하고, 보조선은 반드시 1선의 시작점을 통과하며, 방향은 2선과 같고, 사진에서 보기 쉽게 충분히 길게 표시한다. 직접 그린 1선·2선은 유지하고 보조선은 파란색. 확대·축소·이동해도 원본 이미지 좌표 기준으로 정확히 유지된다."
작성일: 2026-10-16   승인일: 2026-10-16

## 한 줄 목적
목 굴곡을 **정수리 기준이 아니라 얼굴 앞선(턱 앞 → 이마 앞) 기준**으로 재서, 머리 크기·머리카락 모양에 덜 흔들리고 발목과 같은 방식(보조선)으로 통일한다.

## 범위
- 하는 것: **목 굴곡·신전·측방굴곡 세 동작 모두** 새 방식으로 전환 (발목 `kind:"aux"` 구조를 그대로 재사용), 정상값은 **모두 45°**
- 하는 것: 턱·이마 점은 **사람 윤곽(실루엣)에서 자동으로 잡기** — 못 잡으면 손으로 찍기
- 하지 않는 것: 허리·어깨 등 다른 관절 (필요하면 BACKLOG)
- 하지 않는 것: 이미 저장된 옛 방식 기록의 값 변환 — 옛 기록은 옛 방식 그대로 열리고 보인다 (`romAuxLegacy` 기존 장치 재사용)

## 지금과 무엇이 다른가
| | 지금 (v272) | 바꾼 뒤 |
|---|---|---|
| 찍는 점 | 목관절 · 정수리 (2점) + 세로 기준선(자동) | 목관절 · 턱 앞 · 이마 앞 (3점) + 세로 기준선(자동) + **보조선(자동)** |
| ①선 | 목관절 → 화면 위쪽(세로) | 목관절 → 화면 위쪽(세로) — **그대로** |
| ②선 | 목관절 → 정수리 | **턱 앞 → 이마 앞** |
| 각도 | ①선 ↔ ②선 | **①선 ↔ 보조선**(②선과 평행하게 목관절을 지나는 파란 선) |
| 정상값 | 90° | **45°** (굴곡·신전·측방굴곡 모두) |

> 수학적으로 "①선 ↔ 보조선" 각도 = "①선 ↔ ②선" 각도와 같다(보조선은 ②선의 평행 이동). 보조선은 **눈으로 확인하기 위한 표시**이고, 실제로 달라지는 것은 ②선을 **정수리 → 얼굴 앞선**으로 바꾸는 부분이다.

## 동작별 측정점 (승인된 사양)
| 동작 | ①선 시작(축) | ①선 끝 | ②선 시작 | ②선 끝 | 촬영 |
|---|---|---|---|---|---|
| 굴곡 | 목관절 — 목 가장 아래쪽 정중앙 | 세로 기준선(자동, 화면 위) | **턱 앞** — 턱의 전면 | **이마 앞** — 이마의 전면 | 옆 |
| 신전 | 목관절 — 목 가장 아래쪽 정중앙 | 세로 기준선(자동, 화면 위) | **턱 앞** — 턱의 전면 | **이마 앞** — 이마의 전면 | 옆 |
| 측방굴곡 | 목관절 — 목의 정중앙(목젖과 복장뼈 자루의 중간) | 세로 기준선(자동, 화면 위) | **턱끝** — 입술 정중앙에서 수직 아래 끝의 턱 중앙 | **정수리** — 정수리 정중앙 | 정면 |

세 동작 모두: 1선·2선을 그리면 **2선과 평행하고 1선 시작점(목관절)을 지나는 파란 보조선**이 자동 생성되고, 각도 = ①선 ↔ 보조선. 보조선은 사진 대각선 길이만큼 길게 그린다. 확대·축소·이동해도 원본 사진 좌표 기준이라 위치·각도가 유지된다. (발목과 같은 장치)

## 단계
1. **각도 계산 바꾸기** — `romAuxGeo` 가 "①선 = 자동 세로선" 을 처리. 확인: 테스트에서 턱앞(100,300)·이마앞(100,200)(= 수직)이면 0°, 45° 기울이면 45°
2. **테스트 먼저** — `tests/rom-aux.test.js` 에 위 계산 테스트 4개 (0°·45°·90°·점이 모자랄 때 null). 확인: 지금은 실패
3. **점 정의·화면** — `ROM_JOINTS` neck.flex 를 aux 로, 점 이름·안내 문구 교체, 보조선 그리기. 확인: 폰에서 점 3개를 찍으면 파란 보조선이 목관절을 지나 길게 그려짐
4. **옛 기록 호환** — 저장된 옛 목 굴곡 기록을 열어 값이 그대로인지. 확인: 가짜 회원(홍길동)으로 옛 기록 열기 → 각도 변화 없음
5. **측정가이드·엑셀** — `ROM_GD` 4줄 문구, 관리자 엑셀 1선·2선·각도축 문구. 확인: 가이드 팝업에 점 4개가 보이고, 엑셀에 발목 문구가 섞이지 않음
6. **회차 비교 표시** — 옛 방식 기록에 "이전 측정 방법" 표시 (질문 1 답에 따라 생략 가능). 확인: 리포트에서 섞인 회차가 구분됨
7. **문서·점검표** — CHANGELOG·TESTING·ADR(측정 정의 변경 기록). 확인: `/ship` 이 통과

## 확인이 필요한 질문 (3개)
1. **정상값(normal)을 몇 도로 할까요?**
   지금은 90°(정수리 기준)입니다. 얼굴 앞선 기준은 값이 더 작게 나옵니다.
   **추천: 45°** — 경추 굴곡의 교과서 기준(45~50°)이고, 새 기준과 성격이 맞습니다. 다만 과거 기록과 "정상 대비 %" 가 크게 달라집니다. (90° 유지도 가능하나 새 방식에서는 거의 도달할 수 없어 늘 "부족"으로 나옵니다)
2. **자동 인식은 어떻게 할까요?**
   MediaPipe 는 턱 앞·이마 앞을 직접 주지 않습니다.
   **추천: 자동 인식은 목관절만 잡고, 턱 앞·이마 앞은 손으로 찍기** — 발목(복사뼈·비골두)과 같은 수준의 정확도를 기대할 수 없어서입니다. (대안: 얼굴 윤곽 점으로 추정 → 정확도 낮음)
3. **목 신전·측방굴곡도 같이 바꿀까요?**
   **추천: 굴곡만 먼저** — 한 동작으로 실제 측정해 보고 좋으면 신전·측방굴곡으로 넓히는 편이 안전합니다. (신전도 같은 얼굴 앞선을 쓰면 일관되지만, 젖힌 자세에서 턱 앞 점을 찍기 어려울 수 있습니다)
