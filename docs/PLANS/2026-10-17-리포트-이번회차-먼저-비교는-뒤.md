## 한 줄 목적
리포트를 **1부 "이번 회차 결과"**(선택한 회차의 체형·ROM·거북목·척추 균형 사진과 수치를 전부)와 **2부 "회차 비교"**(기준 회차 → 선택 회차의 변화)로 나눠, 고객이 먼저 "이번에 잰 것"을 다 보고 그다음 "얼마나 바뀌었나"를 보게 한다.

## 지금 구조 (v307)
01 종합 결과(변화 칸 포함) → 02 회차별 변화 → 03 체형 정렬(사진) → 04 관절 가동범위(막대 ○→●) → 05 척추·거북목(띠 ○→●) → 06 측정 사진(**비교 쌍**) → 07 측정 기록 → 08 판정 기준.
이번 회차 사진은 체형만 따로 있고, ROM·거북목·척추 사진은 06 의 비교 쌍 안에만 섞여 있어 "이번 회차에 잰 것" 을 한눈에 볼 수 없다.

## 바뀐 뒤 구조
**1부 · 이번 회차 결과 (n차 · 날짜)** — 비교 표시 없이 이번 값과 판정만

2. 체형 정렬 — 정면·측면 사진 + 막대 (지금 03 그대로)
3. 관절 가동범위 — **ROM 동작마다 사진 1장 + 각도·정상 대비 %·판정** 카드 (04 표와 같은 부위 순서)
4. 척추 균형 · 거북목 — **사진 + 각도 + 판정 구간 띠(이번 값 ●만)**

**2부 · 회차 비교 (기준 회차 → n차)** — 회차가 2개 이상일 때만
5. 변화 요약 — 4항목의 기준 회차 값 → 이번 값, ▲▼ (지금 01 의 변화 칸)
6. 회차별 변화 — 그래프 (지금 02)
7. 관절 가동범위 변화 — 막대 ○→● (지금 04)
8. 척추 균형 · 거북목 변화 — 띠 ○→● (지금 05)
9. 사진 비교 — 기준 회차 · 이번 회차 사진 쌍 (지금 06)
10. 측정 기록 — 회차별 전체 수치 (지금 07)

**판정 기준 · 안내 · 서명** (지금 08)

## 단계
1. **모델: 1부 카드 목록** — `current` + 테스트 먼저 — 확인: `npm test`
2. **화면 1부** — 종합(변화 칸 없이)·체형·ROM 카드·거북목/척추 카드 — 확인: 가짜 회원(홍길동)으로 390px 캡처, 1회차·5회차 둘 다. 사진마다 수치·판정이 붙어 있는지
3. **화면 2부** — 변화 요약·그래프·ROM 막대·띠·사진 비교·기록표를 "회차 비교" 아래로 — 확인: 5회차 회원에서 비교 기준을 2차로 바꾸면 2부만 바뀌고 1부는 그대로. 1회차 회원은 2부가 없음
4. **이미지·PDF** — 같은 순서로 캔버스 재배치 — 확인: 이미지 저장 쪽 수·순서를 화면과 비교, 크기 기록
5. **검토·문서** — reviewer·privacy-guard·ui-checker·ui-designer, 문서 갱신 → `/ship`
