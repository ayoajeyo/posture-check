# PRD (제품 요구사항): 아요바디요

> `/adopt` 로 기존 코드(v262)에서 역으로 작성. **실제로 있는 기능만** 적었다. `{확인 필요}` 는 사용자 답으로 채운다.

## 1. 한 줄 정의
필라테스·PT 센터 트레이너·치료사가 회원 앞에서 폰으로 사진을 찍어 체형·ROM·거북목·척추 균형을 측정하고, 회차별 리포트를 회원에게 건넨다.

## 2. 왜 만드나 (문제)
- {확인 필요: 이 앱을 만들게 된 가장 큰 불편 1~2가지}
- 기존 대안과 다른 점: 설치 없이 링크로 열리고(PWA), 자동 인식(MediaPipe) 후 손으로 점을 고칠 수 있으며, 한국어 A4 리포트·공유 링크가 바로 나온다.

## 3. 사용자
| 사용자 | 상황 | 꼭 필요한 것 | 기기 |
|--------|------|-------------|------|
| 트레이너·치료사(센터 운영자) | 회원 앞에서 촬영·측정 | 빠른 촬영, 자동 점 인식 + 수정 | 안드로이드 폰(Play 앱/TWA), PC 브라우저 |
| 회원 | 카톡 등으로 받은 리포트 이미지·공유 링크(r.html)를 봄 | 폰에서 읽히는 리포트, 센터 전화·예약 버튼 | 폰 |
| 방문자 | 센터 소개 페이지(c.html) | 센터 정보·연락 | 폰 |

## 4. 핵심 기능 (코드에 있는 것)
| 순위 | 기능 | 위치(index.html) |
|------|------|------------------|
| 필수 | 체형분석 — 정면(좌우 높이)·측면(수직선) 사진, 자동 인식 + 점 수정, 점수 | `view-analyze` |
| 필수 | ROM — 목·몸통·어깨·팔꿈치·고관절·무릎·발목 좌우 | `view-rom`, `romSheet` |
| 필수 | 거북목(CVA, 귀-C7 각도: ≥55 정상 / 50~55 경계 / <50 거북목) | `view-fhp` |
| 필수 | 척추 균형(전방 굴곡 사진 ATR: <5° 정상 / 5~7° 관찰 / ≥7° 의뢰) | `view-scol` |
| 필수 | 회원 관리 — 등록·검색·담당자·사진 촬영 동의 서명·회차 기록·2회 비교 | `view-members`, `mbForm`, `signPad` |
| 필수 | 리포트 — A4 여러 쪽 PDF(직접 생성)·이미지 저장·공유 | `view-report`, `pagesOverlay` |
| 중요 | 리포트 공유 링크(기간 제한, 조회·전화·예약 집계) | `shSheet` → r.html |
| 중요 | 센터 소개 공개 페이지 | `view-settings` → c.html |
| 중요 | 로그인·여러 기기 동기화(Supabase) | `authGate` |
| 중요 | PRO: 30일 체험 → Google Play 월 구독 / 이용 코드 | `proGate`, `trialEnd` |
| 중요 | 운동 라이브러리·프로그램 배정, 상담 기록, 결제(매출) 기록, 현황 대시보드 | `view-exercise`, `view-consult`, `view-sales`, `view-dash` |
| 중요 | 백업 파일 내보내기·불러오기(JSON) | 회원 화면 |
| 관리자 | 관리자 코드로 켜는 점 수정 기록·엑셀·정확도 재채점 | `admSheet`, `admPanel` |

## 5. 사용자 흐름 (주 사용자 기준)
```
회원 선택(또는 등록 + 동의 서명) → 측정 탭(체형/ROM/거북목/척추 균형) → 촬영 → 자동 점 → 점 수정 → 측정 저장
→ 리포트 → PDF·이미지 저장 / 회원에게 공유 / 공유 링크
```
- 한 번 쓰는 데 걸리는 목표 시간: {확인 필요}
- 가장 자주 반복하는 행동: 촬영 → v254 부터 거북목·척추 균형은 [측정] 한 번에 바로 촬영 화면.

| 화면 | 역할 | 주 버튼 |
|------|------|---------|
