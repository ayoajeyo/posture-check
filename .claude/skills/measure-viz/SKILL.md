# 측정 데이터 보여 주기

목표: **한눈에 "괜찮은가?" 를 알 수 있고, 전문가가 봐도 믿음이 가는** 표시. 견본은 `design-system/styleguide.html` 8번, 클래스는 `design-system/tokens.css` 의 "측정 데이터" 부분.

## 1. 숫자 표기
| 종류 | 형식 | 예 |
|------|------|----|
| 각도 | 소수 1자리 + `°` 붙여서 (같은 크기) | `18.4°` |
| 길이 | 소수 1자리 + 작은 단위 | `1.1cm` |
| 점수 | 정수 + 작은 단위 | `63점` |
| 차이 | 부호 + 방향을 말로 | `오른쪽 0.7cm 높음` (`+0.7` 만 쓰지 않음) |
| 날짜 | `2026.10.14`, 그래프 축은 `10.14` | |
- 모든 숫자에 `font-variant-numeric: tabular-nums` (자릿수 정렬).
- 계산은 원래 정밀도로, **보여줄 때만** 반올림한다. 반올림 함수는 `js/logic/` 에 두고 테스트한다.

## 2. 상태 3단계
| 상태 | 색 | 배지 글자 |
|------|----|----------|
| 정상 | `--ok` / `--ok-bg` | 정상 |
| 주의 | `--warn` / `--warn-bg` | 주의 |
| 개선 필요 | `--bad` / `--bad-bg` | 개선 필요 |
- **색만으로 알리지 않는다** — 항상 배지 글자를 함께 (색약·흑백 인쇄 대비).
- 기준값(정상 범위)은 코드 한 곳(`js/logic/` 상수)에 두고 화면·리포트가 같이 쓴다. 출처를 주석에 적는다.

## 3. 어떤 그림을 쓰나
| 보여줄 것 | 그림 | 클래스·방법 |
|----------|------|-----------|
| 값 하나가 정상 범위 안인가 | 정상 범위 막대 | `.range` (`--lo --hi --val` 은 0~100 위치) |
| 왼쪽·오른쪽 비교 | 두 줄 막대 | `.pair` / `.pair-row` (작은 쪽 `.is-low`) |
| 시간에 따른 변화 | 선 그래프 | SVG 직접 (아래 4번) |
| 여러 항목 요약 | 목록 + 배지 | `.list-item` + `.badge-*` |
| 관절 가동 범위(ROM) | 정상 범위 막대 + 숫자 | 원형 게이지 대신 막대 |
**쓰지 않는 것**: 원형(파이)·도넛·3D·레이더 차트, 무지개 색, 그림자·그라데이션 그래프, 범례 상자(그래프에 직접 글자로).

## 4. 추이 그래프 (라이브러리 없이 SVG)
- 크기 `viewBox="0 0 320 140"`, 왼쪽 축 글자 3개(최소·중간·최대)만, 가로 기준선은 연한 `--line`.
- 목표 범위는 연한 초록 띠(`#ECFDF3`) 하나.
- 선 2px 네이비, 점 3.5px(흰 속 + 네이비 테두리), **마지막 값만** 진한 점 + 글자.
- 날짜 글자는 처음·가운데·끝 3개. 측정이 1회뿐이면 그래프 대신 "측정 2회부터 변화가 보입니다".
- `role="img"` + `aria-label` 에 값을 글로 적는다 (견본 참고).

## 5. 사진 위 측정점·선
| 요소 | 스타일 |
|------|--------|
| 측정점 | 지름 12px 원, 네이비 채움 + 흰 테두리 2px |
| 사용자가 고친 점 | 같은 원 + 바깥 고리 1px 네이비 (구분용) |
| 측정 선·각도선 | 2px 네이비 실선 + 흰 외곽 1px (어떤 배경에서도 보이게) |
| 기준선(수직·수평) | 1.5px 회색 점선 `6 4` |
| 각도 글자 | 13px 700 흰 글자 + 네이비 둥근 바탕(6px) |
- 캔버스는 `devicePixelRatio` 만큼 키워서 그린다 (흐림 방지, `camera-photo` 스킬).

## 6. 리포트에서
- 표: `항목 | 측정값 | 정상 범위 | 상태` 4열 고정. 측정값은 오른쪽 정렬.
- 같은 항목은 화면과 리포트에서 **같은 이름·같은 순서·같은 소수 자리**.
- 인쇄용 색은 `print-color-adjust: exact`, 막대·배지는 흑백 인쇄에서도 글자로 구분된다.

## 7. 점검
- [ ] 숫자에 단위와 소수 자리가 규칙대로인가
- [ ] 상태가 색 + 글자로 표시되는가
- [ ] 정상 범위 출처가 코드 한 곳에 있는가
- [ ] 390px 에서 그래프 글자가 11px 이상이고 겹치지 않는가 (`scripts/screenshot.py` 로 확인)
