# 개인정보 보호: 아요바디요

> 이 문서는 (1) 앱 안에서 보여 줄 **동의 문구**, (2) 공개할 **개인정보처리방침**의 재료다.
> `DATA.md` 를 바탕으로 `/privacy-policy` 가 초안을 만든다. 최종 문구는 법률 전문가 확인을 권장한다(법적 조언이 아님).

## 1. 원칙 (개인정보보호법 기본)
- **최소 수집**: 꼭 필요한 것만. "혹시 몰라서" 받지 않는다.
- **동의 먼저**: 사진·서명 같은 민감한 정보는 **수집 전** 동의. 동의 날짜·방법을 기록.
- **목적 밖 사용 금지**: 측정용 사진을 홍보에 쓰지 않는다(별도 동의 필요).
- **보관 기간**: 정하고 지킨다. 회원 삭제 요청 시 지체 없이 삭제.
- **안전 조치**: 비밀키 보호, 접근 권한 최소, 비공개 저장소.
- **처리방침 공개**: 앱과 스토어에 링크.

## 2. 앱 안 동의 문구 (회원 등록 화면 — 현재 v263 실제 문구)
```

신체 사진 촬영·보관에 동의함 (체크한 날짜를 기록)

[체크하면 열리는 서명 팝업 `signPad`]

신체 사진 촬영·보관에 동의하시면 아래 칸에 회원님이 직접 서명해 주세요.
서명은 이 회원의 리포트 마지막 장 '판정 기준'의 회원 확인 칸에 작게 표시돼요.
리포트를 이미지나 공유 링크로 보내면 서명도 함께 들어갑니다.
[지우기] [취소] [서명 완료]
```
표시 위치는 v292(문서형 리포트)부터 08 판정 기준의 '회원 확인' 칸이다(그 전에는 1쪽 회원 이름 아래).

- 하네스 권장 문구와 차이: 목적·항목·보관 기간·"동의하지 않아도 다른 기능 사용 가능" 안내가 화면에 없다 → BACKLOG.
- 계정(센터) 단위 동의: 가입 시 이용약관·개인정보 및 민감정보 처리 동의 → `ayo_profiles.agreed_terms`, `agreed_sensitive`(시각).
