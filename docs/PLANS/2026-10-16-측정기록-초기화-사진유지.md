# 계획: 사진은 남기고 측정만 비우기 (한 번만 쓰는 정리 기능)
상태: 완료        (초안 → 승인됨 → 진행 중 → 완료 / 폐기)
요청: "현재까지 촬영한 모든 사진은 지우지 않고 측정기록을 초기화 한 다음 수정전 상태로 만들 수 있어? 이유 — ① 최신 측정법이 얼마나 정확한지, 오류를 찾기 위해 ② 이전 측정 자료를 재활용하기 위해 ③ 이전 사진들을 최신 방법으로 측정할 때 오류수정 학습에 쓰기 위해. 물론 이번 단 한 번만 적용."
범위 답변: ① 체형분석·ROM·거북목·척추 균형 **모두** ② 예전값은 **남기지 않음**
작성일: 2026-10-16   승인일: 2026-10-16

## 한 줄 목적
지금까지 찍은 사진을 **그대로 둔 채** 측정 결과만 비워서, 모든 사진을 **최신 측정법으로 다시 재는** 출발선에 놓는다.

## ⚠️ 가장 먼저 알아 두실 것
예전값을 남기지 않기로 하셨으므로, **잘못되면 되돌릴 방법은 백업 파일뿐입니다.**
그래서 이 기능은 **백업을 먼저 받지 않으면 실행되지 않게** 만듭니다. (백업 → 확인 입력 → 실행)

> **2026-10-16 변경**: 사용자 결정으로 **백업은 조건이 아니라 '선택'** 이 되었습니다(ADR-014). 아래 56·65줄의 '백업 없이는 실행 못 하게 막음' 도 같은 이유로 적용되지 않습니다. 앱 자체의 내보내기·서버 저장 기능은 그대로입니다.
> **2026-10-16 (v277)**: 단추 잠금 기준은 '한 번 실행했는가' 가 아니라 **'남은 측정 기록이 0건인가'** 입니다.

## 범위
- 하는 것: `records`(체형분석) · `roms`(ROM·거북목 CVA·척추 균형 ATR) 의 **측정 결과만** 비우기
- 하는 것: 사진은 한 장도 지우지 않음 — 기기 저장소(blobs)·서버 사진함(photos 버킷) 그대로
- 하는 것: 회원·회차(1차/2차)·측정 날짜·메모 그대로 유지
- 하지 않는 것: 회원 삭제, 사진 삭제, 공유 링크 변경
- 하지 않는 것: 일괄 자동 재측정(아래 "왜 비우기만 하나" 참고)

## 무엇이 비워지고 무엇이 남나
| 종류 | 남는 것 | 비워지는 것 |
|---|---|---|
| 체형분석 (`records`) | `photos.front.img`·`photos.side.img`(원본 사진), 회원·날짜·키 | `points`(측정점), `score`(점수), `f`·`sd`(판정값), `groups`(판정 문구), `thumbs`(측정선 그려진 썸네일) |
| ROM·거북목·척추 균형 (`roms`) | `img`(원본 사진), `imgK`, `roll`, 회원·관절·동작·좌우·날짜 | `pts`(측정점), `value`(각도), `pct`(정상 대비 %), `refCustom`(기준선 수정) |
| 사진 (blobs·서버 버킷) | **전부 그대로** | — |
| 관리자 수정 기록 (`admx:`) | {질문 2} | {질문 2} |

**사진이 없는 옛 기록**(각도 숫자만 남은 회차)은 다시 잴 수 없으므로 **건드리지 않고 그대로 둡니다.** 건너뛴 개수를 결과에 알려 드립니다.

## 왜 "비우기만" 하고 일괄 재측정은 안 하나
1. 사진 수백 장에 자동 인식을 연속으로 돌리면 폰이 멈추거나 중간에 끊길 위험이 큽니다
2. **목적 ③(학습)에는 비우는 쪽이 더 맞습니다** — 기록을 열면 그 자리에서 최신 방법으로 자동 인식이 돌고, 원장님이 고쳐서 저장하면 "자동 인식 → 원장님 수정" 한 쌍이 그대로 학습 자료가 됩니다 (지금 쓰는 학습 방식과 동일)
3. 목적 ①(정확도 확인)도 같은 방식으로 쌓입니다 — 고친 양이 곧 자동 인식의 오차입니다

## 데이터 영향
- 새 필드 없음. **지워지는 것은 측정값뿐이고 개인정보(이름·연락처·사진)는 그대로**입니다.
- `DATA.md` 등급으로는 S2(측정 기록)만 영향, S3(사진·서명)은 손대지 않습니다.
- **서버 동기화**: 비운 기록이 `ayo_items` 로 올라가 집 PC·다른 기기에도 같은 상태로 반영됩니다. 한쪽에서만 되돌릴 수 없습니다.
- 이미 회원에게 보낸 **공유 링크 리포트 이미지는 그대로**입니다 (별도 저장이라 영향 없음).

## 위험과 되돌리는 법
| 위험 | 일어날 때 | 되돌리는 법 |
|---|---|---|
| 측정값이 다 사라져 되돌리고 싶다 | 실행 직후 마음이 바뀜 | **백업 파일 복원이 유일** → 그래서 백업 없이는 실행 못 하게 막음 |
| 중간에 앱이 꺼져 일부만 비워짐 | 기록이 많을 때 | 하나씩 처리하고 진행 상황을 저장 → 다시 실행하면 남은 것만 이어서 |
| 집 PC 가 옛 데이터를 다시 올려 되살아남 | 다른 기기가 오래된 상태로 동기화 | 실행 전 모든 기기에서 `/sync`(최신으로 맞추기), 실행 후 다른 기기 앱을 한 번씩 열어 받기 |
| 사진까지 지워질까 걱정 | — | 사진은 **다른 칸·다른 저장소**에 있어 코드가 손대지 않음 + 가짜 회원 시험으로 먼저 확인 |
| 회원에게 보여줄 지난 기록이 없어짐 | 상담 중 지난 회차를 보여줘야 할 때 | 비우기 전에 **지난 회차 리포트를 PDF로 저장**해 두시길 권함 |

## 단계
1. **가짜 회원으로 시험 준비** — 홍길동(010-0000-0000)으로 체형분석 1건·ROM 2건을 만든다. 확인: 기록 3건이 보인다
2. **비우기 함수 만들기** — 측정 칸만 비우고 사진 칸은 건드리지 않는다. 확인: 자동 테스트로 "사진 칸은 그대로, 측정 칸은 빈값"
3. **백업 강제 + 2단계 확인 창** — 백업을 받지 않았으면 단추가 막히고, 실행 전 "비우기" 를 직접 입력해야 진행. 확인: 백업 없이 눌러도 실행되지 않는다
4. **진행률·이어하기** — 100건마다 저장하고 멈춰도 이어서. 확인: 중간에 앱을 닫았다 열면 남은 건수부터
5. **가짜 회원으로 실제 실행** — 확인: 사진 3장 그대로, 측정값 비어 있음, 기록을 열면 **최신 방법으로 자동 인식**이 돌아감
6. **실제 데이터 실행** — 백업 → 실행 → 결과(비운 건수·건너뛴 건수) 확인
7. **문서·점검표·ADR** 정리, 실행 후 단추는 관리자 화면에서 숨김(한 번만 쓰는 기능)

## 확인이 필요한 질문 (3개)
1. **실행 장소** — 병원 폰에서? PC 브라우저에서?
   **추천: PC 브라우저(크롬)** — 기록이 많을 때 훨씬 안정적이고, 백업 파일도 PC 에 바로 저장됩니다. 단 PC 에 지금 데이터가 모두 동기화돼 있어야 합니다.
2. **관리자 수정 기록(`admx:` 보관본)도 함께 비울까요?**
   **추천: 함께 비움** — 옛 측정법 기준의 '수정 전/후' 라 새 측정과 섞이면 정확도 채점·학습이 오염됩니다. (사진은 그대로 남습니다)
3. **"측정 비우기" 단추를 어디에 둘까요?**
   **추천: 관리자 모드 화면 맨 아래, 빨간 테두리로 분리** — 실수로 누르기 어렵게. 실행이 끝나면 "이미 실행함(날짜)" 으로 바뀌어 다시 못 누르게 합니다.
