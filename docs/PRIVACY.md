# 개인정보 보호: {프로젝트명}

> 이 문서는 (1) 앱 안에서 보여 줄 **동의 문구**, (2) 공개할 **개인정보처리방침**의 재료다.
> `DATA.md` 를 바탕으로 `/privacy-policy` 가 초안을 만든다. 최종 문구는 법률 전문가 확인을 권장한다(법적 조언이 아님).

## 1. 원칙 (개인정보보호법 기본)
- **최소 수집**: 꼭 필요한 것만. "혹시 몰라서" 받지 않는다.
- **동의 먼저**: 사진·서명 같은 민감한 정보는 **수집 전** 동의. 동의 날짜·방법을 기록.
- **목적 밖 사용 금지**: 측정용 사진을 홍보에 쓰지 않는다(별도 동의 필요).
- **보관 기간**: 정하고 지킨다. 회원 삭제 요청 시 지체 없이 삭제.
- **안전 조치**: 비밀키 보호, 접근 권한 최소, 비공개 저장소.
- **처리방침 공개**: 앱과 스토어에 링크.

## 2. 앱 안 동의 문구 (회원 등록 화면)
```
신체 사진 촬영·보관에 동의합니다
- 목적: 체형·자세 측정과 변화 비교
- 항목: 정면·측면 신체 사진, 측정 결과
- 보관: {예: 마지막 측정일부터 2년} 또는 삭제 요청 시까지
- 동의하지 않아도 사진 없이 다른 기능은 사용할 수 있습니다
[ ] 위 내용을 확인했고 동의합니다   (서명 ✍)
```
동의 시 저장: `photoConsentAt`(날짜·시간), `consentSignature`(서명 이미지), 동의 문구 버전(`consentVersion: "2026-10"`).

3. 제3자 제공 — {없음 / 있으면 누구에게 무엇을}
4. 처리 위탁 — {예: Supabase Inc.(클라우드 저장), Google LLC(앱 배포)}

3. 피해 가능성이 있으면 당사자에게 알림. 규모·내용에 따라 개인정보보호위원회 신고 의무가 있을 수 있음 — 전문가 확인
