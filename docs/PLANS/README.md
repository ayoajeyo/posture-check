# 계획서 보관함

> 구현 전에 승인받은 **계획서**가 쌓이는 곳이다. "왜 이렇게 바꿨지?" 를 나중에 찾을 때 `ADR`(큰 결정)과 함께 본다.

## 만드는 법
- `/plan 하려는 일` → 계획서만 만들고 승인을 기다린다.
- 개인정보·서버·삭제·결제·로그인·배포 설정·큰 변경이 걸린 `/feature` `/fix` 는 **자동으로** 계획서를 만들고 승인 전에 멈춘다.
- 판정 기준과 양식은 `.claude/skills/plan-gate/SKILL.md`.

## 파일 이름
`YYYY-MM-DD-제목.md` (예: `2026-10-16-회원삭제-서버데이터.md`)

## 상태
| 상태 | 뜻 |
|------|-----|
| 초안 | 작성됨, 승인 전 (구현 금지) |
| 승인됨 | 사용자가 OK, 구현 가능 |
| 진행 중 | 구현하는 중 |
| 완료 | 구현·검토 끝, 실제와 다른 점은 "실제 구현" 에 기록 |
| 폐기 | 하지 않기로 함 (이유 한 줄) |
