사용자가 **회고**를 요청했다. 목적은 코드가 아니라 **AI 가 일하는 환경**(이 하네스)을 고쳐 다음 작업이 더 정확하고 싸게 되게 하는 것. 이 명령은 **제안만** 한다. 사용자는 코딩 초보다.

대상: $ARGUMENTS (비우면 이번 대화. `docs/HANDOFF.md`·`git log -15`·최근 `docs/PLANS/` 도 근거로 본다)

## 찾을 곳 (해당하는 것만)
| 분류 | 이런 일이 있었으면 | 고칠 곳 |
|------|------------------|--------|
| **길 찾기** | 필요한 파일·정보를 찾느라 오래 걸림, 숨은 연결(이 파일 바꾸면 저 파일도) | `docs/ARCHITECTURE.md` 에 "어디에 무엇이" 한 줄, CLAUDE.md 에는 **안내 한 줄만** |
| **자동 점검** | 훅·테스트가 잡을 수 있었던 실수를 AI 가 함 | 새 테스트(`scripts/test_*.py`, `npm test`)나 훅. 이미 있는데 안 돌던 점검이면 그게 발견 |
| **검토 규칙** | reviewer·ui-checker·privacy-guard 가 놓친 실수 | 먼저 분류: **기계적**(정해진 글자 패턴·금지 함수·파일 위치)이면 규칙 대신 훅·테스트로. **판단**이 필요한 것만 에이전트 규칙에 |
| **CLAUDE.md 다이어트** | CLAUDE.md 가 길어져 매번 토큰을 씀 | 세부 규칙은 스킬·docs 로 옮기고 CLAUDE.md 에는 안내만 |
| **토큰 낭비** | 큰 파일 통째로 읽기, 같은 명령 반복, 긴 출력 | 스크립트 출력 줄이기, 서브에이전트에 맡기기, `/handoff` 시점 |
| **효과 없는 지시** | 있어도 AI 행동이 안 바뀌는 문장 | 삭제 |
| **정보 접근** | 꼭 필요한 정보를 AI 가 볼 수 없었음 (로그인 화면, 서버 로그, 폰 화면) | 도구 연결 (`app-capture`, 로그 보기 등) |
| **취향·인수인계** | 사용자가 같은 디자인 지적을 반복, 다음 할 일을 잃어버림 | `docs/TASTE.md` 확정 취향, `/handoff` |

## 고칠 위치를 꼭 구분
- **틀(harness_framework)** 에 고쳐야 모든 앱이 좋아지는 것 → "틀" 로 표시. 틀 폴더에서 고친 뒤 각 앱에 `update-harness.ps1`.
- **이 앱만**의 것 → "이 앱" 으로 표시.

## 보고 형식
```
## 회고: {대상}
| # | 심각도 | 분류 | 무슨 일이 있었나 (근거) | 제안 | 고칠 곳 (틀/이 앱 · 파일) |
|---|-------|------|----------------------|------|------------------------|
가장 먼저 할 것: #… (이유 한 줄)
진행하려면 번호로 알려 주세요. 틀 수정은 harness_framework 폴더에서 합니다.
```
심각도: 높음(같은 실수가 또 날 것 · 개인정보·배포 위험) / 중간(시간·토큰 낭비) / 낮음.

## 규칙
- 근거 없는 일반론 금지. 이번 작업에서 실제로 일어난 일만.
- CLAUDE.md 는 모든 대화에 들어가므로 아껴 쓴다. 새 규칙은 가능하면 훅·테스트 > 스킬·에이전트 > CLAUDE.md 순서로.
- 사용자가 고르기 전에는 아무 파일도 고치지 않는다.
