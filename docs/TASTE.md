# 디자인 취향 기록

> 사용자가 디자인을 보고 "좋다·싫다·이렇게" 라고 말한 것을 쌓는 곳. AI 는 화면을 만들거나 고치기 전에 이 문서를 읽고 따른다.
> `UI_GUIDE.md` 가 기본 규칙이고, 이 문서는 그보다 구체적인 **사용자의 감각**이다. 둘이 부딪히면 사용자에게 물어 UI_GUIDE 를 고칠지(ADR) 정한다.

## 기록하는 법 (AI 가 한다)
- 사용자가 디자인에 대해 반응하면 **그 자리에서** 아래 "기록" 표에 한 줄 추가한다. 사용자 말은 고치지 않고 그대로.
- 같은 취지의 말이 두 번 나오면 "확정 취향" 으로 올리고 기록 줄에 `→ 확정` 표시.
- `/design` 에서 시안을 고르면 고른 것과 이유를 기록한다.
- 앱에 상관없는 취향이면 "공통", 이 앱에만 해당하면 "이 앱만" 으로 나눈다.

## 확정 취향 — 공통 (모든 앱)
- 같은 뜻의 버튼·메뉴는 모든 화면에서 이름과 모양을 똑같이 한다.
- 메뉴·버튼 아래에 중복 설명 문구를 넣지 않는다.
- 인쇄·공유용 리포트는 긴 이미지 한 장이 아니라 A4 여러 장으로.
- 포인트 색은 로고 네이비 `#1E2A4A` 하나. 심플·깔끔.

## 확정 취향 — 이 앱만
- 테마: 밝은 클리닉 느낌(A안 색) + 관절 선택은 몸 그림을 눌러 고르는 방식(C안). 단계적으로 적용 중 (2026-10)
- 메인 색은 청록에서 로고 네이비 `#1E2A4A` 로 바꿨다 (2026-10-14)
- 메뉴 이름·형식은 모든 화면에서 똑같이: `📖 촬영 매뉴얼`, `📍 측정가이드` — 이 앱은 이미 메뉴 앞 이모지를 쓰고 있어 UI_GUIDE 8번(이모지 금지)의 예외로 유지한다. 바꿀지는 사용자 결정
- 펼침·접기 버튼은 "○○ 보기 / ○○ 접기" (UI_GUIDE 7번)
- 리포트는 검사 결과지 같은 **문서 한 벌**(머리글 → 01~08 번호 섹션 → 바닥글). 대시보드 카드·타일·별점·색 칸 히트맵은 쓰지 않는다. 좌/우는 색이 아니라 줄로, 전→후는 ○→● 한 가지 기호 (2026-10-16, v292)
- 글꼴: 지금은 본문 IBM Plex Sans KR · 숫자 IBM Plex Mono · 브랜드 Cormorant Garamond. 하네스 표준(Pretendard)과 다르지만 **지금 글꼴을 유지**한다. 바꿀지는 BACKLOG "다음" 에서 시안 비교 후 사용자 결정

## 공통 취향을 다른 앱에도
공통 취향은 틀(`harness_framework`)의 이 문서에도 있어야 다음 새 앱이 이어받는다. 공통 취향을 확정하면 사용자에게 알린다:
"틀에도 옮기려면 harness_framework 폴더에서 Claude 에게 '앱이름 의 TASTE 공통 취향을 틀로 옮겨줘' 라고 하세요."
