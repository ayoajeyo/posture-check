# 한국 개인정보 실무 체크

## 꼭 갖출 것 (앱 출시 전)
| 항목 | 구현 | 근거 문서 |
|------|------|----------|
| 수집 항목·목적 명시 | 회원 등록 화면 동의 문구 | PRIVACY.md 2절 |
| 민감 정보(신체 사진) 별도 동의 | 체크 + 서명 + 날짜·문구 버전 저장 | DATA.md `photoConsentAt`, `consentSignature`, `consentVersion` |
| 보관 기간과 파기 | 기간 지나면 삭제 안내/자동 삭제 | DATA.md 보관 기간 |
| 처리방침 공개 | `privacy.html` 링크를 앱 설정·스토어에 | PRIVACY.md 3절 |
| 열람·삭제 요청 창구 | 이메일 + 앱 내 삭제 기능 | PRIVACY.md 4절 |
| 위탁 고지 | Supabase·Google 등 | PRIVACY.md 3절 4항 |
| 안전 조치 | 비공개 저장소, RLS, 비밀키 분리 | ARCHITECTURE.md 7절 |

## 동의 팝업 구현 규칙
- 체크박스 기본값은 **해제**. 체크하면 서명 팝업 → 서명 완료 시 체크 유지, 취소하면 체크 해제.
- 저장: `photoConsentAt`(ISO), `consentSignature`(PNG dataURL, 흰 배경 투명 제거), `consentVersion`.
- 리포트 머리글 회원 이름 아래에 서명을 높이 8mm 로 표시(동의 증빙). 없으면 "동의 서명 없음" 대신 아무것도 표시하지 않는다.
- 동의 철회: 회원 상세 → "사진 동의 철회" → 사진 삭제 여부 확인 → `photoConsentAt: null`, 철회일 기록.

## 서명 패드 (팝업)
- `<canvas>` 가로 전체·세로 160px, 선 2.5px 검정, `touch-action: none`, `pointer` 이벤트로 그린다.
- 버튼: [다시 쓰기] [취소] [서명 완료]. 빈 서명은 완료 불가.
- 저장 전 흰 배경으로 합성해 JPEG 아닌 **PNG** 로(선이 뭉개지지 않게). 크기 600×240 이하.

## `/privacy-policy` 가 만드는 `privacy.html`
DATA.md 의 S2·S3 행 → "수집 항목·목적·보관기간" 표. ARCHITECTURE.md 외부 서비스 → "처리 위탁". PRIVACY.md 3절 7항 → 책임자. 심플 UI 로 한 페이지, 시행일 표기, 앱 설정 화면과 스토어에 링크.

## Play Console "데이터 안전" 매핑
| DATA.md 등급 | Play 항목 |
|---|---|
| 이름·연락처 | 개인 정보 → 이름, 전화번호 |
| 신체 사진 | 사진 및 동영상 → 사진 / 건강 및 피트니스 → 건강 정보 |
| 서명 | 개인 정보 → 기타 |
| Supabase 저장 | "데이터가 전송됨" 예 / 암호화 전송 예 / 삭제 요청 가능 예 |
기기에만 저장하면 "수집" 아님으로 표시 가능하나, 동의 문구는 그대로 둔다.

## 하지 말 것
- 동의 전에 카메라를 켜지 않는다.
- "마케팅 활용" 을 측정 동의에 끼워 넣지 않는다(별도 체크).
- 미성년자 데이터는 법정대리인 동의가 필요 — 출생연도로 14세 미만이면 안내 후 등록 보류.
